- Added fields to specify the size of start, stop, and person title slides. Default size is 1400 by  1050 pixels ([#2](https://github.com/jimorc/trilliumshowfx/issues/2)).
- Allow defining new slide size as default ([#2](https://github.com/jimorc/trilliumshowfx/issues/2), with discussion in [#3](https://github.com/jimorc/trilliumshowfx/issues/3)).
- Add checkbox to create start and end slides or not ([#10](https://github.com/jimorc/trilliumshowfx/issues/10)).
- Allow defining checkbox setting as default ([#10](https://github.com/jimorc/trilliumshowfx/issues/10)).
- Allow saving start and end slides text as default values ([#3](https://github.com/jimorc/trilliumshowfx/issues/3)).
- Added Don't Sort radiobutton to group of radiobuttons that select the sorting to be done ([#12](https://github.com/jimorc/trilliumshowfx/issues/12))
- Added button to save the selected sort order as a default ([#12](https://github.com/jimorc/trilliumshowfx/issues/12))
